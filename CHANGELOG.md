# Changelog

All notable changes to Repair Snooze are documented here. This project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-17

### Added
- Initial stable public release, confirmed working in Home Assistant by the repository owner.
- Automatic snoozing of Marketplace “Restart required” repair issues after integration updates.
- Support for hiding existing Marketplace restart repairs during initial setup.
- Temporary repair ignores that expire on the next actual Home Assistant restart.
- Protection for manually ignored repairs and unrelated issues.
- Home Assistant UI setup flow and translation strings.
- Simulated lifecycle tests and Marketplace installation metadata.
